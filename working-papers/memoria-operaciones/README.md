# Memoria de las operaciones

**Status:** Working paper — arquitectura congelada v0.2  
**Target v1.0:** 2026-10-11

## Tesis provisional

El capitalismo computacional produce una tensión entre fragmentación de la experiencia y acumulación infraestructural de capacidades: mientras el sujeto puede perder capacidad de totalización, las infraestructuras adquieren capacidades crecientes para recordar, relacionar, coordinar y actuar.

## Núcleos

- memoria de las formas;
- memoria de las operaciones;
- pipelinización;
- signo operativo;
- mapa externalizado;
- agencia y capacidad de intervención.
