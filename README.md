# Araí Research

Araí Research es un laboratorio independiente de investigación y escritura sobre humanidades digitales, inteligencia artificial, educación, sistemas computacionales, agencia y soberanía tecnológica.

El repositorio organiza una cadena pública de trabajo:

**idea → nota → ensayo / working paper → protocolo → repo reproducible → preprint → contraste público → revisión → publicación / transferencia**

## Líneas

### Humanidades / teoría
- **El lector total** — lectura, poesía, algoritmo y agencia.
- **Memoria de las operaciones** — infraestructura, historicidad y capacidad operacional.
- **Trabajo muerto y saber distribuido** — apropiación, trazabilidad, portabilidad y federación.

### Investigación empírica
- **CortX / SOR-TOR** — mediación de IA en interpretación literaria, trayectorias semánticas y reificación de segundo orden.

### Computación / matemática
- **Khayyam** — validación prospectiva y estudio de firmas en problemas computacionales.

## Estados editoriales

- **Research note**: apunte público de trabajo; no implica una tesis cerrada.
- **Essay**: pieza argumentativa de circulación pública.
- **Working paper**: manuscrito desarrollado y abierto a crítica.
- **Preprint**: manuscrito estable, preparado para circulación académica y posible envío a revista.
- **Repository / code**: software, protocolos, notebooks o materiales reproducibles.
- **Release**: versión fechada y congelada.

## Principios

1. Diferenciar claramente hipótesis, evidencia y afirmaciones.
2. Publicar también límites, incertidumbres y resultados negativos útiles.
3. No convertir datos sensibles o material de aula en contenido público.
4. Preservar trazabilidad de versiones y decisiones.
5. Favorecer reproducibilidad y crítica antes que marketing.
6. Mantener separadas investigación pública, operación interna y documentación comercial.

## Citar

Cada pieza contiene su propio bloque de citación y estado. Las versiones estables se etiquetarán con tags/releases y, cuando corresponda, se archivarán en un repositorio con DOI.
